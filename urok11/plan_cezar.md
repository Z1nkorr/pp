## Алгоритм
1. Задать алфавит для шифрования
2. Спросить у пользователя текст для шифрования
3. Задать шаг шифрования
3.1. нормализовать шаг шифрования
4. Найти в алфавите текущ. букву из текста и прибавить к её индексу шаг шифрования, если новый индекс для буквы выходит за пределы алфавита, то надо начинать считать индекс с началаа алфавита
5. Сформировать по букве новую строчку из зашифрованного текста, если текущая буква из текста отсутствует в алфавите, то переносим эту букву в шифроваанный текст как есть
6. Вывести зашифрованный текст как есть
